<p align="center">
  <b>The original 2012 Forza Horizon, native on Windows and Linux, and online again.</b><br>
  A static recompilation of the Xbox 360 game that runs from your own copy: Horizon World, leaderboards and Rivals on a public server (or host your own), a co-op festival, mods, HD textures and a frame rate you set.
</p>

<p align="center">
  The official online services closed on 22 August 2023 (<a href="https://forza.net/news/forza-horizon-online-services-closure">Turn 10's notice</a>).
</p>

## Get involved

Bugs and ideas go to the [issue tracker](https://github.com/FH1-ReImagined/ForzaHorizon1-ReImagined/issues); chat and help on [Discord](https://discord.gg/yu7zScdcWw). Pull requests are welcome.

**Official links.** The only official sources are this GitHub organization, [forza.dyotson.dev](https://forza.dyotson.dev) and the [Discord](https://discord.gg/yu7zScdcWw). ReImagined never ships prebuilt game files or zip downloads of the game.
